# Anti-Brainrot

A non-clinical attention training web app with browser-based cognitive tasks and progress tracking. It is designed for self-directed practice and transparency about what the data does and does not mean.

Live site: https://moussagerges9.github.io/Anti-Brainrot/

## Overview
- Attention assessments: Flanker, Go/No-Go, N-back, and PVT
- Training sessions with adaptive difficulty
- Progress visualization and session summaries
- Clear disclaimers about non-clinical use

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Zustand for state management

## Getting Started
1. Install dependencies
   - `npm install`
2. Start the dev server
   - `npm run dev`
3. Build for production
   - `npm run build`
4. Preview the production build locally
   - `npm run preview`

## Notes
- This app is not a medical device and does not provide clinical assessment or diagnosis.
- The production build output is written to `dist`.
